# Flyengine

### A basic game engine based on a modified version of the [Raylib](https://www.raylib.com/) engine and [Box3D](https://github.com/erincatto/box3d)

## Building and compiling
### Windows
* Flyengine for windows uses [CMake](https://cmake.org/)
* Download [Microsoft Visual Studio 2022](https://visualstudio.microsoft.com/) or later
* Make sure CMakeLists.txt exists
* Under Build click "Build" or "Compile"
### Linux
* Flyengine for Linux uses SCONS
* Install python using the older installer
* Select add to path 
* Do ```pip install scons```
* Wait for scons to install and type ```scons platform=linux```
